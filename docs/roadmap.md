# Roadmap and validation gates

The [baseline's validation sequence](company/canonical-baseline-v1.0.md) is a sequence of hypotheses and evidence gates, not completed milestones. Phase 0 specifies PFC and AC concepts and verifier/safety/privacy invariants. After Phase 0 acceptance, Validation Gate A — Corpus & Reference Architecture Bootstrap encodes 10 public incidents as L0 candidate PFCs, checks whether the PFC abstraction represents materially different real mechanisms without forcing them into the model, and specifies 3 reference architecture shapes sufficient for later executable-PFC validation. Gate A claims no reproduction or verification and implements no Phase 2+ work. Once it passes, Phase 1 implements only the timeout-after-external-commit vertical slice on Go, PostgreSQL, and a payment simulator. Later V0 work may broaden to ten PFCs, three reference services, five fault primitives, and one CLI/proof format, but each expansion depends on evidence from the prior stage.

The canonical order after Gate A remains: develop the three specified reference architectures; make three PFCs executable; conduct five expert interviews; reproduce one real historical external incident, then three materially different historical incidents; find a design partner; run a pilot; reach first payment. None of these outcomes is claimed here. Product packaging and commercial scope should follow evidence, not precede it.

Kill or pivot if applicability stays noisy, false positives destroy trust, engineers refuse runner installation, failure mechanisms fail to transfer, experiments cannot be reproduced, or users see demo value without operational value. Record negative evidence and the decision before expanding the corpus or deployment surface.

Explicit current non-goals: SaaS dashboard, billing, enterprise RBAC/SSO, uncontrolled production chaos, automatic global incident ingestion, large connector ecosystem, AI-issued safety or proof verdicts, Phase 2+ implementation, and claims of broad portability or market validation. The baseline's possible future mesh-control and commercial features remain future possibilities.
