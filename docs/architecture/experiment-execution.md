# Experiment compilation and execution

Compilation starts only after an `APPLICABLE` verdict. It maps the PFC's abstract causal operations into versioned adapters for the identified application/build and environment. The resulting candidate experiment manifest binds PFC/AC versions, logical operation, application/build and environment identity, fault primitive and injection point, parameters and finite experiment space, invariant, required observers, cleanup/reset requirements, random seed if used, requested safety level, PFC safety restrictions, and other inputs required by safety planning. Compilation does not authorize execution. A mapping that cannot place the fault at the required causal point leaves execution `UNKNOWN` without injection.

Safety planning evaluates the compiled candidate against the [levels and controls](../safety.md). It either produces an approved execution plan bound to that candidate or denies execution with an explicit reason. No mutation or fault injection occurs without the approved plan. The local runner records the approved plan and run identity, verifies preconditions, executes within time/rate/blast-radius budgets, monitors abort conditions, and collects ordered evidence. A safety denial does not change the applicability verdict; when execution was requested, its result remains `UNKNOWN` (not established), and the denial reason is recorded. A failed, aborted, partially observed, or non-reproducible run is `UNKNOWN` unless sufficient evidence already establishes `EXPOSED` and remains trustworthy. The verifier decides; the runner never infers a verdict from exit status alone.

Phase 1's required primitive is loss of the external payment response **after** the simulator commits an effect and **before** the Go caller receives success. A test-only deterministic barrier keyed by run/logical-operation identity must durably append the effect, establish authoritative commit evidence, hold success delivery, and then trigger configured response loss. Correlated barrier and request/response evidence establish the injection point; arbitrary sleeps and wall-clock races cannot. Merely delaying a response or dropping a request before commit does not exercise the PFC. Reset between runs must restore database and provider ledger state or use isolated run IDs. The declared experiment space must enumerate the tested retry count/timing, response-loss placement, and workload concurrency; untested combinations are outside a resilience verdict.
